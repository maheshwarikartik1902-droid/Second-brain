## Features

- **Document Management** : Upload and organize MDX/text files in a structured, searchable dashboard
- **Note Creation** : Write and manage individual notes with a clean, distraction-free editor
- **AI Summarization** : Generate concise summaries of any document with a single click
- **AI Chat** : Ask questions about your documents and get contextual, grounded answers
- **Authentication** : Secure, seamless sign-in and session management via Clerk
- **Real-time Sync** : Powered by Convex for instant, reactive data updates across sessions
